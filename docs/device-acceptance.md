## 最先完成：权限和一次响铃

目前通知、悬浮窗已允许；精确闹钟、锁屏响铃页、电池优化豁免待开启，HyperOS 自启动尚未确认。“已保存”不等于“手机一定会响”。

- [ ] **开启权限**：仪表盘 → 权限与桌面 → 分别开启精确闹钟、锁屏响铃页；设置电池优化豁免和 HyperOS 自启动。返回点“权限已调整 · 重新检查提醒”。预期：可确认权限显示“已允许”。
- [ ] **前台响铃**：新建“调试－前台响铃”，两分钟后，系统铃声。预期：准时出现响铃页，停止后本次不重复响。
- [ ] **锁屏响铃**：新建“调试－锁屏响铃”，两分钟后，回桌面并锁屏。预期：按系统授权显示锁屏提醒，铃声／振动与停止正常。
- [ ] **稍后提醒**：设置稍后提醒一分钟，响铃时点击。预期：首次停止，一分钟后再提醒；之后停止不继续触发。
- [ ] **关闭宠物不影响闹钟**：开启两分钟后的闹钟，再关闭悬浮宠物。预期：宠物消失，闹钟仍准时响。

手机连电脑时，在项目目录运行只读采集：

```powershell
.\scripts\collect-device-diagnostics.ps1
```

输出版本、权限、退出原因与当前轻伴进程的错误日志，保存在 `dist/device-debug/diagnostics-时间/`。不截屏、不读密钥或资料、不清日志、不改权限、不重启 App、不上传文件。测试结束取消自己创建的闹钟和事项，避免以后误响。
