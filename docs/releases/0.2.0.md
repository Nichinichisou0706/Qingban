# 0.2.0 完成记录

日期：2026-10-06。范围是新的 Android 手机应用；按照铭哥要求不进行实机测试，动态角色采用已有素材互动动画。

## 本轮落地

| 原先缺口 | 当前实现 |
| --- | --- |
| 批量方案按项保存 | `ItemService.applyBatch` 与 Room 事务；整体校验、去重、统一撤销；系统调度另报状态 |
| 本次及以后的系列修改 | 切分旧系列与新系列，在同一事务里保存；旧发生次保留 |
| 简单先后关系 | 真实事项 ID 的依赖集合；循环和时间顺序校验；拓扑展示与离线顺序记录 |
| 备忘与日历增强 | 清单、置顶、上移下移、安排日期、月历／周历、截止日显示 |
| 资料导入仅文本 | Android PDFBox、中文 ML Kit、DOCX XML；混合 PDF 按缺文字页面 OCR；导入后先预览 |
| 资料更新与失效 | 新正文版本与五版历史、有效期、停用、来源关联、删除派生记忆选择 |
| 检索与旧引用 | 关键词加本地字符向量排序；远程权限、有效期、版本检查；旧资料回答从模型历史中排除 |
| 习惯只在偏好页 | 对话候选、每天一次额度、拒绝冷却、近 14 天统计、分开观察／使用控制 |
| 语音和分享 | Android 系统识别与文字分享先填入输入框，用户发送后执行 |
| 在线曲目 | HTTPS 直链／M3U、离线缓存库、异步试听、耳机断开停止试听 |
| 角色互动 | 状态图片、触摸、轻量动画、尺寸／透明度、临时隐藏、悬浮提醒气泡 |
| 简单 JSON 备份 | 兼容旧 JSON，增加 ZIP 音乐、会话、观察与学习设置；不备份密钥或批准凭据 |
| 弱模型预设与评估 | 完整角色规则、当前工具协议、按日期生成的详细示例；应用内六场景首步评估 |

## 验证证据

最终脚本同时执行架构依赖检查、三个 JVM 测试模块、全部 Android 模块 Lint 和 APK 构建。测试报告位于各模块 `build/test-results/test/`，Lint 报告位于 Android 模块 `build/reports/`。

83 项 JVM 单元测试通过：业务与资料／习惯 53 项、智能体 27 项、模型 HTTP 适配 3 项；失败、错误与跳过均为 0。模块依赖检查与四个 Android 模块 Lint 通过；Lint 有 45 条建议性警告。APK 调试签名通过 apksigner 验证，包名 io.github.ming.qingban、versionCode 2、versionName 0.2.0。

已验证的关键场景包括批量参数错误不留下数据、整体撤销与版本保护、重复系列分割、长时间跳过后仍能继续计算未来提醒、循环依赖、跨午夜依赖、清单撤销、资料授权撤回、来源更新后的偏好失效、每天一次习惯提议和联网问题恢复。提醒时间计算的单元测试不代表已在手机上响铃。

## 尚需外部验收

本轮没有安装到手机，没有模拟器或 UI 截图验收，没有调用真实模型。Android 资料解析、OCR、语音、ZIP 备份、悬浮桌宠、锁屏与耳机播放都经过编译和 Lint 检查，不能因此宣称运行验收完成。正式体验需要后续在铭哥允许时进行设备测试；模型可以通过应用内评估按钮进行基础检查。

功能边界和导入限制见 README；轻量字符向量不是语义 Embedding，简单依赖也不是大型项目优化器。Live2D 按此次选择不接入。
