## 外部验收边界

按要求未进行手机或模拟器 UI 测试。实际通知、后台提醒、锁屏、耳机路由、语音、文件选择与原文件查看、PDF／OCR、显示适配和长期耗电，由 [手机验收清单](../device-acceptance.md) 覆盖。电脑数据库／ZIP 回归不代表这些系统交互已经在手机通过。

真实模型按铭哥选择本轮不调用。App 和 :integration:model:evaluateModel 电脑入口均已完成，含六项首步与三项多轮场景，只用独立测试数据；用法见 [构建与模型验收准备](../release-preparation.md)。脚本模型回归不代表任何真实模型已通过。

限制按 README：关键词与字符向量检索、简单依赖、有限 ICS 重复规则、静态网页和直链音乐；没有承诺大型优化排程、云同步或任意格式解析。角色素材公开分发许可尚待明确，本轮产物用于铭哥的开发验收。
