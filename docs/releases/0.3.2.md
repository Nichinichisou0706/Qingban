# 0.3.2 手机调试修复

Android versionCode 5。手机调试发现并修复三处问题：分享文字发送后在旋转中重新填回、日历所选日期和周历模式丢失、旧保存结果在旋转中关闭再次打开的编辑框。

分享请求现在只消费一次；日期、浏览月份和周历模式保存恢复；操作结果显示后由 ViewModel 消费，主列表与全部事项使用同一机制。模型接口、数据库和模块依赖保持原样。

133 项本地回归、架构检查、debug / release Lint 与构建、签名和资源检查通过。已同签名覆盖安装到 Android 15 手机，并重测恢复问题、悬浮切换与点击。详见 [调试报告](../device-debug-report-0.3.2.md) 与 [手机清单](../device-acceptance.md)。真实模型、真实音频、锁屏和长期后台场景仍需按清单验证。

增加只读采集脚本 `scripts/collect-device-diagnostics.ps1`，输出版本、权限、退出原因和当前轻伴进程错误日志，文件仅保存在本机。
