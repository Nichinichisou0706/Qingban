# 轻伴 0.4.5

轻伴是一款本地优先的 Android 生活助手，将一句话安排、待办、备忘、日历、音乐闹钟、番茄钟、习惯与资料库融合在单个 GPT 娘的交互中。这个 Release 提供当前完整源码和正式安装包。

## 本版更新

- 全部事项、待办和备忘支持多选、全选、批量删除及整批撤销；待办多选栏固定显示，长页面也能直接操作。
- 仪表盘、习惯和专注统计的七天窗口以今天居中；日历周／三日视图围绕选中日，自动对齐显示。
- 手机桌宠常态为 46 × 76 dp，与展开后中心角色一致；轮盘为 188 dp，保留五秒淡化、动态切换、拖动贴边和功能入口。
- 日常生活待办采用长期重复习惯，与闹钟共用重复规则；当天完成和清单不会完成后续日期，可选择仅删除本次或整个系列。
- 智能体同步支持长期习惯的创建、频率与提醒时间追问、当天完成、分页查询和删除确认，补充详细预设和回归场景。

已有功能包括月／周／三日／日历、统一时间滚轮、番茄钟与正计时、模型供应商配置列表与模型发现、本地打卡督促、逾期调整建议、资料导入检索、偏好学习和完整备份。

## 安装

下载附件 `Qingban-0.4.5-release.apk`，支持 Android 8.0 及以上。包名 `io.github.ming.qingban`，versionCode 为 12。已有同签名正式版可覆盖升级并保留数据。

`SHA256SUMS.txt` 提供安装包校验和。GitHub 自动生成的 Source code 附件为本版源码，不是手机安装包。
