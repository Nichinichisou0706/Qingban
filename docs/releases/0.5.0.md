# 轻伴 0.5.0

轻伴是一款本地优先的 Android 生活助手，将一句话安排、待办、备忘、日历、音乐闹钟、番茄钟、习惯与资料库融合在单个 GPT 娘的交互中。这个 Release 提供当前完整源码和正式安装包。

## 本版更新

**界面重构（清爽卡片流）**
- 底栏改为「今天 · 日历 · 备忘 · 闹钟 · 我的」；原仪表盘成为「我的」页，番茄钟从快捷入口和工具页打开。
- 右下角 GPT 娘头像是唯一的助手入口，点开为带图标的快捷轮盘，点空白处收起。
- 长按事项进入多选；删除、完成、编辑后底部提示可直接「撤销」。
- 当天事项按上午／下午／晚上／待安排分组，习惯以淡紫色条标识；统一白底细边卡片、圆形勾选、分段切换和日历「回到今天」。
- 聊天页消息带头像，气泡与输入框重新设计。

**可靠性**
- 在系统设置中开启精确闹钟或通知权限后，等待权限的闹钟会自动重新调度。
- 稍后提醒改用系统闹钟通道，减少 HyperOS 省电导致的延后；缺少精确闹钟权限时退回普通提醒而不是失败。
- 智能体取消事项改为先出方案、确认后执行；「别取消」「不要改」等否定说法不再被视为修改授权。

## 安装

下载附件 `Qingban-0.5.0-release.apk`，支持 Android 8.0 及以上。包名 `io.github.ming.qingban`，versionCode 为 16。已有同签名正式版可覆盖升级并保留数据。

`SHA256SUMS.txt` 提供安装包校验和。GitHub 自动生成的 Source code 附件为本版源码，不是手机安装包。
